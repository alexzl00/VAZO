3. VERCEL ENVIRONMENT SETTINGS
Production:
  VITE_SITE_URL=https://vazo.vercel.app
  PORADNIK_RELEASE_MODE=off
Preview:
  VITE_SITE_URL=https://vazo.vercel.app
  PORADNIK_RELEASE_MODE=preview

Set these in Vercel > Project > Settings > Environment Variables.
Ensure each variable has the correct Production/Preview target.
Vercel uses the unchanged "Vite" framework preset, npm run build, dist.
When a custom domain is purchased, only VITE_SITE_URL needs changing in
Vercel (plus DNS/domain attachment and host redirects).

IMPORTANT: A Preview deployment is a separate URL and noindex, not private
access control. Do not put personal/user/production financial data in it.

4. BUILD LOCALLY (FULL REPO REQUIRED)
  npm ci
  npm run build
  npm run test:poradnik

Default release mode is OFF. This must create NO /poradnik HTML in dist.

To build the preview locally (Unix/macOS shell):
  VITE_SITE_URL=https://vazo.vercel.app PORADNIK_RELEASE_MODE=preview npm run build
  PORADNIK_RELEASE_MODE=preview npm run test:poradnik

Expected preview files:
  dist/index.html
  dist/poradnik.html
  dist/poradnik/demo-architektury.html
  dist/poradnik/poradnik.css
  dist/poradnik/VAZO-logo.png

Expected Production/off files:
  dist/index.html
  (no dist/poradnik.html, no demo article, no sitemap.xml)

The demo guide is meant to be tested on a Vercel Preview URL, not via
"npm run dev": we intentionally did not integrate the independent SSG
routes into the existing SPA dev server.
